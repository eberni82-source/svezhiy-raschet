# Свежий расчёт

Сервис прогноза спроса и контроля свежести для малого бизнеса со скоропортящимся товаром: пекарен, кофеен, кулинарий, столовых, магазинов у дома.

- `index.html` — сайт (публикуется через GitHub Pages).
- `kabinet.html` — личный кабинет. Без бота открывается как пример условной пекарни (данные в браузере); с ботом — свои данные, вход по коду из `/web`.
- `bot/` — Telegram-бот: план на утро, вечерние скидки, сроки годности, рассылки. Запуск и настройка — в `bot/README.md`.
- `site-src/` — исходники сайта и кабинета. После правок: `python site-src/build.py` — он пересоберёт `index.html`, `kabinet.html` и `bot/web/kabinet.html`.

Демо-данные пекарни (`bot/data/demo_sales.csv`) сгенерированы для примера и не являются реальными продажами.
