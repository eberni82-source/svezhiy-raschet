# Свежий расчёт — Telegram-бот (MVP)

Бот для пекарни или кафе. Каждое утро присылает план: сколько испечь каждой позиции. Вечером подсказывает, при каком остатке на витрине ставить скидку. Напоминает о продуктах с истекающим сроком годности. В конце дня просит отметить итоги и на этом учится.

Работает на чистом Python 3.10+: **ничего устанавливать через pip не нужно**.

---

> **Нужен один файл?** `svezhiy_bot.py` — тот же бот целиком в одном файле: его можно просто скопировать. Токен впишите в `BOT_TOKEN` в начале файла (или в `.env` рядом) и запустите `python svezhiy_bot.py`. Демо-данные он генерирует сам.

## Запуск за 10 минут

### 1. Создайте бота в Telegram
1. Откройте в Telegram **@BotFather** и отправьте `/newbot`.
2. Имя бота: `Свежий расчёт`.
3. Адрес (username) должен заканчиваться на `bot`, например `svezhiy_raschet_bot`. Если занят, придумайте свой.
4. BotFather пришлёт **токен** — строку вида `1234567890:AAH...`. Это пароль от бота: не публикуйте его и не присылайте в чаты.

Необязательно, но красиво (тоже в @BotFather):
- `/setdescription` — «Считаю, сколько испечь, чтобы меньше выбрасывать. Напоминаю о сроках годности.»
- `/setuserpic` — аватарка.

### 2. Узнайте свой Telegram ID
Напишите боту **@userinfobot**, он ответит числом `Id`. Это нужно, чтобы бот присылал вам заявки на пилот и разрешал делать рассылку.

### 3. Настройте
В папке бота скопируйте файл `.env.example` под именем `.env` и заполните:
```
BOT_TOKEN=1234567890:AAH...ваш токен
ADMIN_IDS=123456789
```
Несколько администраторов (вся команда) — через запятую.

### 4. Запустите
- **Windows:** установите Python с python.org (при установке отметьте «Add Python to PATH»), затем дважды кликните `run.bat`.
- **macOS / Linux:** `./run.sh` или `python3 bot.py`.

В окне появится «Бот запущен». Пока окно открыто, бот работает.

### 5. Проверьте
Откройте своего бота → `/start` → напишите город → `/demo`. Бот загрузит демо-данные условной пекарни, покажет, сколько она теряла, и пришлёт план на завтра.

## Рассылки

**Автоматические** — каждому подключённому заведению, по его местному времени:

| Когда | Что | Поменять |
|---|---|---|
| 06:00 | План выпечки на сегодня + продукты с истекающим сроком | `/time утро 05:30` |
| 17:00 | При каком остатке на витрине ставить скидку | `/time вечер 16:00` |
| 21:00 | Просьба отметить итоги дня (кнопками, 1 минута) | `/time итоги 20:30` |

Заведение может выключить рассылку командой `/stop` и включить обратно через `/start`.

**Ручная рассылка всем** (только администраторы):
```
/broadcast Добавили прогноз для кофеен — попробуйте /plan
```
Бот покажет предпросмотр и число получателей, отправит после нажатия «Отправить». Тех, кто заблокировал бота, он сам исключит из рассылки.

**Статистика:** `/stats` — сколько пользователей, у кого есть данные, последние заявки.

## Заявки с сайта
Кнопка на сайте ведёт по ссылке `https://t.me/<адрес_бота>?start=pilot`. Бот задаёт 4 вопроса (заведение, город, тип, контакт) и присылает заявку всем администраторам.

## Свои данные продаж
Пришлите боту CSV-файл: выгрузку из кассы или таблицу из Excel («Сохранить как» → CSV). Разделитель `;` или `,`, кодировка UTF-8 или Windows-1251.

```
дата;товар;испечено;продано;закончилось;цена;себестоимость;дождь
2026-10-17;Круассан классический;55;55;15:40;120;40;0
2026-10-17;Багет;38;29;;90;34;0
```
Обязательные колонки: `дата`, `товар`, `продано`. Остальные делают прогноз точнее:
- `испечено` — бот покажет, сколько вы списывали и сколько списывали бы по его плану;
- `закончилось` — время, когда товар кончился (реальный спрос был больше продаж);
- `цена`, `себестоимость` — чтобы понимать, что дороже: остаток или пустая полка;
- `дождь` — 1/0, бот сам посчитает, как погода влияет именно на вашу точку.

Цену можно задать и командой: `/price Круассан 120 40`.

## Как бот считает
1. **Спрос** = продажи, а если товар кончился раньше закрытия, то с поправкой вверх.
2. **Прогноз** = средний спрос за последние 2 недели × профиль дня недели (за 8 недель) × поправка на дождь × событие (`/event`).
3. **Сколько печь** — модель «газетчика»: чем выше маржа, тем больше запас. Круассан (цена 120, себестоимость 40) печём с запасом. У сэндвича с маржой 50% печём ровно по прогнозу.
4. **Вечерняя скидка**: после 17:00 обычно продаётся ~22% дневного объёма. Если на витрине больше, чем это значение × 1,2, бот советует скидку 30%, а при двойном превышении — 50%.

Код модели: `core/forecast.py`. Сайт считает по той же формуле.

## Чтобы бот работал круглосуточно
Ноутбук для защиты подойдёт. Для пилота нужен сервер: любой недорогой VPS с Linux и Python 3.10+.
1. Скопируйте папку бота в `/opt/fresh-bot` и создайте там `.env`.
2. `sudo cp fresh-bot.service /etc/systemd/system/ && sudo systemctl enable --now fresh-bot`
3. Логи: `journalctl -u fresh-bot -f`

Данные хранятся в одном файле `fresh.db` (SQLite) — делайте его копию.

## Файлы
```
bot.py               — бот: команды, кнопки, рассылки по расписанию
core/forecast.py     — модель прогноза и расчёт объёма
core/csv_import.py   — чтение CSV из кассы/Excel
core/storage.py      — база SQLite
core/weather.py      — погода и часовой пояс (Open-Meteo, бесплатно, без ключа)
core/tg.py           — обращение к Telegram Bot API
data/demo_sales.csv  — ДЕМО-данные условной пекарни (не реальные продажи)
tests_offline.py     — проверка всех сценариев без интернета: python tests_offline.py
```

## Ограничения MVP и что дальше
- Погода учитывает только дождь (≥ 1 мм осадков за день). Следующий шаг — температура.
- Партии продуктов вводятся вручную. Дальше: распознавание фото накладной.
- Продажи загружаются файлом. Дальше: прямое подключение к кассе или ОФД.
- Данные демо-пекарни сгенерированы для примера. Реальный эффект нужно измерить в пилоте: списания до и после за 4 недели.
